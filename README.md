
# 💿 Burn CD

> Bring back the mixtape era. One CD at a time.

A retro-inspired interactive music experience that lets you discover songs, create personalized mixtapes, burn virtual CDs, and share your creations with friends.

## ✨ Features

- 🎵 Search for your favourite songs.
- 💿 Create custom mixtapes.
- 🔥 Interactive virtual CD-burning experience.
- 🎧 Built-in music player with playback controls.
- 🎨 Retro pixel-art inspired interface.
- 💌 Add personalized messages to your CDs.
- 🔗 Share your mixtapes with friends.
- 📱 Responsive user interface.

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- iTunes Search API
- Deezer API
- Google Fonts

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/burn-cd.git
```

### Navigate to the project

```bash
cd burn-cd
```

### Run locally

Open the project in VS Code and launch `index.html` using Live Server.
